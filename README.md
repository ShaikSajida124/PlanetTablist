🪐 Planet Tablist

A responsive interactive Planet Tablist project built as part of my JavaScript learning with freeCodeCamp.

Users can select different planets and view information about them through an interactive tab-based interface.

✨ Features

- 🪐 Interactive planet selection
- 📑 Tablist navigation
- 🔄 Dynamic content updates using JavaScript
- 📱 Responsive design
- ♿ Accessible navigation with appropriate ARIA attributes

🛠️ Built With

- HTML5
- CSS3
- JavaScript

🎯 What I Learned

Through this project, I practiced:

- Working with JavaScript events
- Updating content dynamically
- Creating an interactive tablist
- Using "data-*" attributes
- Improving accessibility with ARIA attributes
- Managing active states
